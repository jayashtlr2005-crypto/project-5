# Experiment 19: Employee Management System (C++)

## Aim
To design an object-oriented C++ program for storing and displaying employee records using a class and a vector.

## Prerequisites
- A C++ compiler installed (e.g., g++, clang++, or MSVC).
- Basic understanding of classes, objects, constructors, strings, loops, and STL vectors.

## Procedure
1. Include the iostream, vector, and string headers.
2. Define an Employee class with employee ID, name, and salary as data members.
3. Create a constructor to initialize the employee details and a display method to print them.
4. Declare a vector of Employee objects in main.
5. Show a menu to add employees, view all records, or exit.
6. Create and store an Employee object when details are entered, and iterate through the vector to display records.

## How to Compile and Run

### Using G++:
```bash
g++ main.cpp -o employee_management
./employee_management
```

### On Windows (Command Prompt / PowerShell):
```powershell
g++ main.cpp -o employee_management.exe
.\employee_management.exe
```

## Conclusion
The C++ program used a class to represent employee records and a vector to store a dynamically sized collection of employees.
